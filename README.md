# Классификация тональности отзывов: трансформеры

Практическое задание 5 недели курса: улучшить качество классификации
тональности отзывов на фильмы (негативный / нейтральный / позитивный) по
сравнению с TF-IDF + классическими моделями из 4 недели, используя
предобученную трансформерную модель с HuggingFace

## Задача

В 4 неделе был собран пайплайн: NLP-предобработка + TF-IDF +
LogisticRegression / LinearSVC, macro F1 на тесте 0.65. Теперь нужно поднять
качество, при этом можно пожертвовать скоростью работы модели. Для этого:

- выбрать предобученную модель с HuggingFace и обосновать выбор;
- реализовать пайплайн полного дообучения (full fine-tuning) модели на задачу
  классификации тональности;
- опробовать LoRA и сравнить его с полным дообучением;
- для всех подходов показать качество на тестовой выборке и сделать выводы

## Датасет

[ai-forever/kinopoisk-sentiment-classification](https://huggingface.co/datasets/ai-forever/kinopoisk-sentiment-classification)
на HuggingFace, тот же что и в 4 неделе. Три jsonl-файла с полями `text` и `label`:

| label | класс      |
|-------|------------|
| 0     | негативный |
| 1     | нейтральный|
| 2     | позитивный |

| выборка    | размер |
|------------|--------|
| train      | 10 500 |
| validation | 1 500  |
| test       | 1 500  |

Train идеально сбалансирован (по 3 500 отзывов на класс), дубликатов между
train/val/test нет. Длина отзывов в токенах RuModernBERT (перцентили
50/90/95/99): 416 / 964 / 1214 / 1699

## Выбор модели

Взял [deepvk/RuModernBERT-base](https://huggingface.co/deepvk/RuModernBERT-base):

- 150M параметров, архитектура ModernBERT - быстрее и эффективнее классического BERT;
- контекст до 8192 токенов (у BERT-моделей обычно 512) - половина отзывов
  длиннее 416 токенов, а 10% длиннее 964, поэтому длинный контекст тут нужен;
- обучена на ~2T токенов (русский + английский + код);
- на Russian SuperGLUE - лучший средний score среди моделей, с которыми её
  сравнивают авторы (0.737)

## Подход

**Предобработка**: вся предобработка из 4 недели (lowercase, лемматизация,
удаление стоп-слов и пунктуации, склейка отрицаний) для BERT не нужна или
вредна - регистр и пунктуация несут сигнал, лемматизация убирает
грамматическую форму, а стоп-слова и отрицания self-attention обрабатывает
сам. Текст подаётся в токенизатор как есть, обрезка до `max_length=1024`

**Подходы**, которые сравнивал:

1. **Прогон базовой модели через fill-mask** - без обучения, промпт
   `"{текст} Это было [MASK]."` и сравнение вероятностей слов-индикаторов
   тональности ("плохо", "нормально", "отлично" и т.д.) на месте маски
2. **Эмбеддинги + классические модели** - энкодер заморожен, эмбеддинг
   отзыва = mean pooling по последнему слою, поверх `StandardScaler` +
   `LogisticRegression` / `LinearSVC` из 4 недели
3. **Полное дообучение** - `AutoModelForSequenceClassification`, обучаются
   все 153.6M параметров
4. **LoRA** - веса модели заморожены, обучаются только low-rank адаптеры
   (`peft`) и голова классификатора - 4.0M параметров (2.6%)

Training loop написан вручную на PyTorch: свой `Dataset` с
токенизацией на лету, `DataCollatorWithPadding`, fp16 через `torch.autocast` +
`GradScaler`, сохранение лучшей эпохи по macro F1 на validation

**Параметры полного дообучения** (`train.py`):

| параметр | значение |
|----------|----------|
| lr | 5e-5, линейный warmup 6% шагов, дальше линейное затухание до 0 |
| эффективный батч | 32 (батч 4 × накопление градиентов 8) |
| эпохи | 3 |
| оптимизатор | AdamW, weight decay 0.01 (кроме bias и norm) |
| loss | CrossEntropy |
| голова | mean pooling, dropout 0.1 |
| max_length | 1024 |

**Параметры LoRA** (`train_lora.py`) - всё то же самое, кроме:

| параметр | значение |
|----------|----------|
| r / lora_alpha / lora_dropout | 16 / 32 / 0.1 |
| target_modules | `Wqkv`, `Wo`, `Wi` (все линейные слои внимания и MLP) |
| modules_to_save | `head`, `classifier` (голова учится целиком) |
| lr | 3e-4 |

## Результаты на тестовой выборке

| Модель | Accuracy | Precision (macro) | Recall (macro) | F1 (macro) |

| TF-IDF + LinearSVC (4 неделя) | 0.67 | 0.65 | 0.67 | 0.65 |
| RuModernBERT zero-shot (fill-mask) | 0.46 | 0.36 | 0.46 | 0.36 |

| **RuModernBERT LoRA** | **0.741** | **0.734** | **0.741** | **0.736** |

F1 по классам:

## Выводы

- Лучший результат на тесте - **RuModernBERT + LoRA** (r=16, alpha=32,
  lr=3e-4, 2 эпохи): macro F1 0.736, accuracy 0.741. Полное дообучение
  дало 0.729 - разница 0.007 меньше типичного разброса между запусками с
  разными сидами, так что по качеству подходы на одном уровне
- Оба варианта дообучения подняли macro F1 с 0.65 (4 неделя) до ~0.73, а
  F1 нейтрального класса - с ≈0.5 до ≈0.6
- fill-mask без обучения - macro F1 0.36, хуже TF-IDF из
  4 недели
- Эмбеддинги RuModernBERT без дообучения + LogReg / SVM дали 0.65–0.66 -
  столько же, сколько TF-IDF в 4 неделе, нейтральный класс тоже ≈0.5
- LoRA обучает в 38 раз меньше параметров, требует на 1.5 GB меньше
  видеопамяти и сохраняется в 16 MB вместо 600 MB. По времени выигрыша не
  было
- Нейтральный класс остаётся главным источником ошибок во всех подходах

## Как велась работа

Сначала проверил модель без обучения через fill-mask (`baseline.py`), чтобы
понять, адекватна ли она. Варианты перебирал на 30 отзывах -
первые 30 строк `train.jsonl`, сохранял их в отдельный `reviews.jsonl` (в
репозиторий не входит, как и остальные jsonl). Пробовал голосование по
топ-15 слов на месте маски (accuracy ~0.53, нейтральный класс - recall
0.00), другой промпт `"Оценка фильма: [MASK]."` (~0.40, модель уходила в
числа и да/нет) и суммирование softmax-вероятностей слов-индикаторов
(~0.50). Последний вариант прогнал на всём тесте - accuracy 0.46, macro F1
0.36, нейтральный класс не предсказывается вообще - дальше без дообучения
никак

Первый вариант полного дообучения: lr=3e-5 без расписания, батч 4, 4 эпохи,
голова по CLS-токену. Лучшая эпоха - 2-я, macro F1 0.729 на validation. На 3
и 4 эпохах модель переобучалась: train loss падал до 0.16, а val loss рос
с 0.64 до 0.93

На своей RTX 4050 (6 GB) выходило около часа на эпоху.
Пробовал Colab на T4 и Colab TPU v5e-1, но долго подбирал совместимые версии `torch` / `torch_xla`.
В итоге обучал на RTX 5060 8 GB: ~9 минут на эпоху

**Что реально помогло:**

- fp16 (`torch.autocast` + `GradScaler`) - ускорение обучения без потери
  качества
- Второй вариант обучения: warmup + линейное затухание lr, эффективный батч
  32 через накопление градиентов, weight decay не на bias/norm, label
  smoothing 0.1, mean pooling и dropout 0.1 в голове. После первой эпохи
  macro F1 на validation 0.733 вместо 0.711, лучший результат 0.736 вместо
  0.729, и val loss почти не рос. Все правки вносил одним запуском, поэтому
  вклад каждой по отдельности не мерил
- LoRA с lr=3e-4 - вышла на уровень полного дообучения и переобучалась
  меньше: val loss 0.589 → 0.591 на 2-3 эпохах против 0.613 → 0.670 у
  полного дообучения

**Что пробовал, но не сработало:**

- простой fill-mask - на тесте accuracy 0.46, macro F1 0.36,
  нейтральный класс не предсказывается
- Эмбеддинги без дообучения + классические модели из 4 недели - на уровне
  TF-IDF. Лучшее C оказалось очень маленьким (0.001), при C от 0.1 до 1
  качество на validation падало
- TPU v5e-1 в Colab - обучение в итоге заработало, но много времени ушло на
  версии библиотек, а в первом варианте из-за `xm.optimizer_step` модель
  переставала учиться после первой эпохи
- 4 эпохи вместо 3 - после 2-3 эпохи модель начинает переобучаться

## Как воспроизвести обучение

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   PyTorch нужен с поддержкой CUDA - команду под свою видеокарту брать на
   [pytorch.org](https://pytorch.org/get-started/locally/)
2. Скачать `train.jsonl`, `validation.jsonl`, `test.jsonl` со страницы
   [Files and versions](https://huggingface.co/datasets/ai-forever/kinopoisk-sentiment-classification/tree/main)
   датасета в папку `training/`
3. Из папки `training/` запустить нужный скрипт:
   ```bash
   python baseline.py
   python train.py
   python train_lora.py
   python train_embeddings.py
   ```
   Каждый скрипт в конце печатает качество на test. При первом запуске
   модель `deepvk/RuModernBERT-base` скачивается с HuggingFace - нужен
   доступ в интернет. Полное дообучение и LoRA требуют GPU минимум с 8 GB
   видеопамяти
4. Скопировать `training/best_model_lora` в `service/`, если LoRA
   переобучалась

## FastAPI-сервис

Сервис использует LoRA-адаптер (лучший результат на тесте). Базовая модель
`deepvk/RuModernBERT-base` при старте скачивается с HuggingFace, адаптер
вливается в её веса через `merge_and_unload()`. Работает и на GPU, и на CPU

Запуск:
```bash
cd service
uvicorn main:app --reload
```

Пример запроса:
```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"text": "Посмотрел вчера в кино и до сих пор под впечатлением. Сюжет держит в напряжении до самого конца, актёры играют так, что веришь каждому слову, а музыка идеально дополняет происходящее на экране. Давно так не смеялся и не переживал за героев одновременно. Однозначно буду пересматривать и советую всем, кто любит хорошее кино."}'
```

Ответ:
```json
{
  "label": 2,
  "label_name": "Хороший",
  "probability": 0.5718,
  "probabilities": {
    "Плохой": 0.0200,
    "Нейтральный": 0.4082,
    "Хороший": 0.5718
  }
}
```

Модель обучалась на длинных отзывах с Кинопоиска (медиана 416 токенов), и
короткие фразы в одно предложение она часто относит к нейтральному классу:
например, "Отличный фильм, давно так не смеялся!" - нейтральный с
вероятностью 0.71. Полное дообучение ведёт себя так же

`GET /health` — проверка живости сервиса
